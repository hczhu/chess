# Chess game notes

Always add `file-created-at:` to the YAML front matter of chess game Markdown
files. Use only the file's creation date in `YYYY-MM-DD` format, with no time
or timezone. Determine the date in America/Los_Angeles by default. Preserve
this value on later edits. When creating a note from `game-template.md`,
replace the date placeholder.

Write game tags as Logseq hashtags, using `#tag` for single words and
`#[[Tag with spaces]]` for multiword names. Preserve the user's tag wording.
